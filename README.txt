GOALS GYM WEBSITE DEMO — INFINISTACK DIGITAL SOLUTIONS

Files:
- index.html: complete responsive one-page website
- assets/: website images and gym photographs supplied/generated for the concept

Preview locally:
1. Extract the ZIP file.
2. Open index.html in a browser. Keep the assets folder beside index.html.

Publish with GitHub Pages:
1. Create a separate repository for the demo (do not replace the InfiniStack website repository).
2. Upload index.html and the entire assets folder to the repository root.
3. In repository Settings > Pages, choose Deploy from a branch, select main and /(root), then save.
4. Wait for GitHub Pages to provide the demo URL.

Before public launch:
- Confirm Goals Gym has approved the site, logo, photos and generated visuals for public use.
- Confirm phone/WhatsApp number, exact address, opening hours and current training options.
- Confirm whether the older promotional material and the 24/7 statement are still current.
- Confirm the final copy and replace any demonstration imagery that the gym does not approve.
- Current membership prices are intentionally omitted; the website directs visitors to enquire.

This is a concept website, not an official Goals Gym website. The page includes a concept disclaimer in its footer.
